Página con responsiveness para el emprendimiento de Casa.Martiria

Se utilizo un template base para la distribución de contenido 
haciendo migración de html/css previamente construido

Luego se hicieron 2 actualizaciones de contenido y diseño a petición del emprendedor (en diferentes fechas):
- se agregó galeria de imagenes responsive con lightbox2
- más videos de la producción de productos en la sección de proceso.
- modificaciones en el header de #index.
- modificaciones de distribuciones de secciones en #about
- se añadio link de playlist de spotify y link directo a DM de whatsapp para poder hacer cotizaciones directamente con el emprendedor
- se traslado contacto al formulario #about (el formulario de contacto sigue en el proyecto pero esta inactivo)
- se actualizaron imagenes, medidas y precios de los productos
- se actualizo la tipografía en algunas secciones ya que habían discordancias.
